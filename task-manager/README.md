<< برنامه مدیریت کارها >>
این یک برنامه کاملا ساده است و در بستر ترمینال کار میکند . کار ها در یک فایل جداگانه ذخیره میشوند 
این دستور ثابت است : npx tsx cli.ts ...
با دستور ... add "your task" یک کار را اضافه میکنیم
با دستور ... done id ایدی وارد شده به وضعیت انجام شده میرود
با دستور ... list لیست کارها و با list done لیست انجام شده ها میدهد 
با دستور ... remove id آیدی مورد نظر حذف میشود 
رابط گرافیکی عمدا بیرون است
